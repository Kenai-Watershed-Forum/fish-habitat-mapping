5.1 Overview

This chapter documents a stratified proportional random sampling design to select candidate field survey sites within stream reaches whose anadromous fish status is currently unknown. These survey sites support the Last Fish Observed (LFO) field method: crews begin at each launch point and walk upstream until fish are no longer detected. The resulting presence-absence data provide a calibration dataset for models predicting the upper extent of anadromous fish occupancy in the Kenai Peninsula Borough.

This chapter depends on the output of Chapter 4: Knowledge Status of Fish Presence/Absence, where the NetMap stream network was attributed with a fishstatus field using ArcGIS Pro Trace Network tools. Reaches are classified as:

  • "Present" — at or below the most-upstream documented fish observation
  • "Unknown" — above those observations, with no confirmed fish presence or absence

Only "Unknown" reaches are candidate survey locations for this chapter.

5.1.1 Design Rationale

Simple random sampling of stream reaches biases site selection toward low-elevation, high-density valley networks — reaches that are already well-sampled. A stratified proportional random sampling scheme corrects for this by dividing the candidate pool into landscape strata (here, by watershed unit) and allocating survey sites in proportion to each stratum’s share of the total pool. The result is a sample that is statistically sound and representative across the environmental and elevational gradient of the study area.

5.3 Data

5.3.1 Input files

This chapter requires two spatial datasets, both stored in data/input/:

Dataset Path Source
Classified NetMap reaches data/input/netmap/netmap_classified.gpkg ArcGIS output from Chapter 4
Focus HUC boundaries data/input/focus_hucs/focus_hucs.gpkg Project focus area layer (Chapter 2)

The classified NetMap layer must include at minimum:

  • fishstatus — character field with values "Present" or "Unknown"
  • GRADIENT — numeric channel gradient (unitless proportion)
  • OUT_DIST — distance to river mouth (km); used to verify digitization direction
# Classified stream network (output from fish_status.qmd ArcGIS workflow)
streams <- st_read("data/input/netmap/netmap_classified.gpkg")

# Focus HUC boundaries for stratification
hucs <- st_read("data/input/focus_hucs/focus_hucs.gpkg")

# Align coordinate reference systems before any spatial operations
if (st_crs(streams) != st_crs(hucs)) {
  hucs <- st_transform(hucs, st_crs(streams))
}

5.4 Filter to Accessible Unknown Reaches

Starting from the full classified network, two filters are applied in sequence:

  1. Fish status filter: keep only reaches labeled "Unknown".
  2. Gradient barrier filter: remove reaches at or above GRADIENT_MAX, which are assumed to be above natural passage barriers.
streams_unknown <- streams |>
  filter(fishstatus == "Unknown", GRADIENT < GRADIENT_MAX)
NoteGradient barriers and upstream topology

Filtering by GRADIENT < GRADIENT_MAX removes individual steep segments but does not remove flat reaches that lie upstream of a steep barrier. For example, if a 25% gradient cascade separates a flat headwater reach from the rest of the accessible network, the simple attribute filter retains that headwater reach even though it is physically unreachable by anadromous fish.

The topologically correct approach is to identify all barrier segments (where GRADIENT >= GRADIENT_MAX), trace the network upstream from each barrier, and remove the entire inaccessible drainage — equivalent to “Select by Attribute → Upstream Trace → Delete” in ArcGIS Pro. If this level of precision is required, this step should be added to the ArcGIS workflow in Chapter 4, and the exported netmap_classified.gpkg should contain only accessible reaches before arriving at this chapter.

For the current implementation, the simple gradient filter is used as a practical approximation.

5.5 Extract Launch Points

Each candidate survey reach is reduced to a single launch point — the downstream end of the reach, where field crews will begin walking upstream. The NetMap stream network is digitized from mouth to source (the start vertex of each feature is the downstream end), which is consistent with the OUT_DIST attribute: lower OUT_DIST values occur at the start vertex.

st_line_sample() with sample = 0 extracts the start (downstream) vertex of each line geometry.

NoteVerifying digitization direction

Before running this step, confirm that OUT_DIST values are lower at the start vertex than at the end vertex for a sample of reaches. If NetMap data for a different region are digitized in the opposite direction (source to mouth), use sample = 1 instead of sample = 0 to extract the downstream end.

launch_points <- streams_unknown |>
  mutate(geometry = st_line_sample(geometry, sample = 0)) |>
  # Drop any reaches for which a start point could not be extracted
  filter(!st_is_empty(geometry))

5.6 Landscape Stratification

Each launch point is assigned to the watershed unit (HUC) it falls within via spatial join. Points that fall outside all HUC polygons are dropped; these typically represent reaches at the edge of the study area that slightly cross the boundary.

points_stratified <- st_join(launch_points, hucs, join = st_within) |>
  filter(!is.na(.data[[STRATIFY_BY]]))

5.7 Stratified Proportional Sample

5.7.1 Quota calculation

Each stratum receives a site quota proportional to its share of the total candidate pool. Quotas are rounded to whole numbers; a correction step adjusts the stratum with the largest rounding remainder to ensure quotas sum to exactly TARGET_N.

strata_summary <- points_stratified |>
  st_drop_geometry() |>
  count(.data[[STRATIFY_BY]]) |>
  mutate(
    prop      = n / sum(n),
    quota_raw = prop * TARGET_N,
    quota     = round(quota_raw)
  )

# Rounding correction
discrepancy <- TARGET_N - sum(strata_summary$quota)
if (discrepancy != 0) {
  strata_summary <- strata_summary |>
    mutate(remainder = abs(quota_raw - quota)) |>
    arrange(desc(remainder))
  strata_summary$quota[1] <- strata_summary$quota[1] + discrepancy
}

5.7.2 Sampling

Sites are drawn independently within each stratum using slice_sample().

set.seed(SET_SEED)

field_sites <- points_stratified |>
  group_by(.data[[STRATIFY_BY]]) |>
  nest() |>
  left_join(
    strata_summary |> select(all_of(STRATIFY_BY), quota),
    by = STRATIFY_BY
  ) |>
  mutate(sampled = map2(data, quota, \(d, q) slice_sample(d, n = q))) |>
  unnest(sampled) |>
  ungroup() |>
  st_as_sf()

strata_summary |>
  select(
    Stratum              = all_of(STRATIFY_BY),
    `Available reaches`  = n,

5.8.2 Map

library(leaflet)
library(RColorBrewer)

# Reproject to WGS84 for leaflet
field_sites_wgs <- st_transform(field_sites, 4326)
hucs_wgs        <- st_transform(hucs, 4326)

# Color palette by stratum
strata_levels <- unique(field_sites_wgs[[STRATIFY_BY]])
pal <- colorFactor(
  palette = brewer.pal(min(length(strata_levels), 8), "Dark2"),
  domain  = strata_levels
)

leaflet() |>
  addProviderTiles("Esri.WorldTopoMap") |>
  addPolygons(
    data        = hucs_wgs,
    weight      = 1.5,
    color       = "#555",
    fillOpacity = 0.05,
    label       = ~hucs_wgs[[STRATIFY_BY]]
  ) |>
  addCircleMarkers(
    data        = field_sites_wgs,
    radius      = 5,
    color       = ~pal(.data[[STRATIFY_BY]]),
    stroke      = FALSE,
    fillOpacity = 0.85,
    label       = ~paste0(.data[[STRATIFY_BY]], " | OUT_DIST: ",
                          round(OUT_DIST, 1), " km")
  ) |>
  addLegend(
    pal    = pal,
    values = field_sites_wgs[[STRATIFY_BY]],
    title  = "Watershed stratum"
  )
